Every PDF carries more than its pages: who made it and with what, files tucked inside it, and layers that can be switched on and off. Clumsy shows all three.

## Document info

The Info tab in the sidebar (the ⓘ icon) shows what the file says about itself. **File > Document Properties** ([[⌘D]]) opens the sidebar on it.

- **File:** its name, folder, and size.
- **Description:** title, author, subject, and keywords.
- **Origin:** when it was created and last modified, the app that made it, and the PDF producer.
- **Document:** PDF version, page count, the size of the current page (with its paper name, like Letter or ARCH D), whether it's tagged for screen readers, and whether it's set up for fast web view.
- **Contents:** whether it needs a password, has a form or digital signatures, and how many attachments and layers it holds.

Rows the file leaves empty aren't shown, and the text can be selected and copied. The page size follows the page you're on.

> If the Form row says the file is an XFA form and the page only asks you to wait, the file was made for a form app Clumsy doesn't support yet. The real form is inside, but Clumsy can't draw it.

## Attachments

When a PDF has files attached, an Attachments tab (the paperclip) appears in the sidebar, and **View > Attachments** opens it. It lists files attached to the whole document first, then files attached to a spot on a page, with their page.

- **Open** a PDF or Markdown attachment to see it in a new tab. Nothing is written to disk until you save it.
- **Save** (the download arrow) any attachment to wherever you choose.
- Click a page attachment to go to its page. Double-click a row, or press [[Return]], to open or save it.

Double-clicking an attachment's icon on the page does the same as Open or Save.

Clumsy never runs an attachment or hands it to another app. A file can be anything, including a program, so anything other than a PDF or Markdown file is only saved, and you decide what to do with it.

## Layers

Drawings exported from CAD and some brochures put their content on layers: walls on one, electrical on another, notes on a third. When a PDF has layers, a Layers tab appears in the sidebar, and **View > Layers** opens it.

- Check or uncheck a layer to show or hide it. Some files group layers under a heading, and some make a set of layers work like radio buttons, where showing one hides the others.
- **Show All** and **Hide All** do what they say. **Reset** goes back to the way the file shows them.

Page thumbnails and the Document Map follow what you hide. The layers stay the way you set them when you rearrange pages, when another app changes the file, and when you move the tab to another window.

Hiding a layer only changes what you see in Clumsy. Saving doesn't change the file's layers, and printing and Export Pages as Images use the file's own layer settings.
