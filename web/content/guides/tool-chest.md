A tool chest is a list of tools you've saved with their style and a name. "Drywall" is a blue Area with a light fill. "Type A fixture" is the recessed downlight stamp. "Rev 2" is a red cloud. Pick one and the next markup you make looks right and is named right, without touching the colors you use the rest of the time.

The name is what makes it useful. Markup made with a saved tool is named after it, so the [Markups list](/guides/markups) counts "Type A fixture" and "Type B fixture" separately even though they're the same stamp, and a measurement export sorts by trade instead of by color.

## Open it

The Tool Chest tab is in the sidebar on every PDF, the toolbox icon after Markups. View > Tool Chest opens it too.

Saved tools are listed by group, each with a little picture of what it makes. Click one to use it. It stays highlighted while it's the tool in use; pick any other tool and it lets go.

The first time you open it there's a starter set: Approved, Rejected, and For Review stamps, a red revision cloud, a yellow highlight, and Length and Area measurements in feet and inches. Keep them, change them, or clear them.

## Save a tool

- **From a tool's menu.** Open the arrow beside Shapes, Measure, Highlight, Text, or Draw and choose **Save as Tool…** at the bottom. It saves that tool with the color, fill, and thickness you have now.
- **From a markup you like.** Select it, right-click, and choose **Add to Tool Chest…**, or use Tools > Add Markup to Tool Chest…. It takes the markup's kind, style, and name, and works on markup made in other apps too.
- **From the tab.** **Save Tool…** at the top of the tab saves whatever tool you're using. With a stamp armed, that's the stamp.

Each way opens the same sheet: a name, an optional group, and the style.

| Setting | What it does |
| --- | --- |
| **Name** | Shown in the chest, and written on every markup the tool makes |
| **Group** | Sorts the chest, like "Electrical" or "Drywall". Pick an existing one or type a new one |
| **Tool** | Which tool it is. Switch it here to turn a rectangle into an area, say |
| **Color**, **Fill**, **Dashed**, **Thickness**, **Opacity** | The style, the same choices as the toolbar's menus |
| **Units** | Measurements only: the units and precision to show, or the page's own |

Review stamps keep their own color.

## Use one

- Click it in the Tool Chest tab.
- In the Command Palette ([[⇧⌘P]]), type "Tool:" and part of its name.
- Add it to the right-click menu (below) and pick it there.

Using a saved tool never changes your everyday style. Draw a blue "Drywall" area, then pick the plain Area tool, and you're back to your own color.

Highlight, Text, and Draw tools can be saved for their color and size, but those markups aren't named after the tool. Shapes, stamps, underlines, strikethroughs, and measurements are.

## Change, reorder, and delete

Right-click a tool, or click the **⋯** that shows when you point at it:

| Choice | What it does |
| --- | --- |
| **Edit…** | Rename it, move it to another group, or change its style |
| **Duplicate** | A copy right below it, to make a variation |
| **Add to Context Menu** | Puts it in the tools {{mac: row}}{{win: list}} at the top of the page's right-click menu |
| **Delete** | Removes it. **Undo** shows at the top of the tab |

Drag a tool to reorder it. Drop it in another group to move it there.

The **⋯** at the top of the tab has **Export Tool Chest…**, **Import Tool Chest…**, **Add Starter Tools**, and **Clear Tool Chest**.

Every window shares one chest. A tool saved in one shows up in the others.

## Share it

**Export Tool Chest…** (in the tab's **⋯** menu and the Tools menu) saves every tool as a `.clumsytools` file. To share one group, right-click its heading and choose **Export**.

**Import Tool Chest…** adds the tools from a file, and so does dropping a `.clumsytools` file on the window. A tool that's already in your chest is updated. If an imported tool has the same name and group as one of yours, Clumsy asks once: **Replace** yours, or **Keep Both**.

Send a team the same file and everyone's markups come out with the same names and colors, which is what makes a combined markup list or measurement export make sense.

> A `.clumsytools` file is plain text you can read and edit. It holds names, groups, and styles, nothing from your documents.
