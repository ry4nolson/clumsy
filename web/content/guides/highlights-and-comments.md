Everything here saves into the PDF as standard annotations, so the next person sees your markup in whatever they open the file with.

## Highlight, underline, strike through

Press [[H]] for the Highlight tool, then drag across text. Or select text first with the Select tool and choose Tools > Highlight Selected Text, or right-click the selection.

The arrow beside the Highlight button opens its options:

- **Highlight**, **Underline**, or **Strikethrough**. The button remembers which one you used last.
- A color.
- **Show highlights**, which hides every highlight in the document without deleting any. Useful when you want to read the clean page for a minute.

Start a highlight drag away from any text and you get a freehand highlighter stroke instead, for marking up scans and drawings that have no selectable text. Its thickness is in the same menu.

## Text on the page

[[T]] is the Text Note tool. Click where you want it and type. Color and size are in the button's menu. Text notes are for filling in blanks and labeling things: the words sit right on the page.

## Drawing

[[D]] is Draw. Color, thickness, and opacity are in its menu. Changing a setting applies to your next stroke, not the ones already on the page.

## Images

Tools > Add Image{{mac:  ([[⌃⌘I]])}} places a picture on the page. Drag its corners to resize. You can give an image alt text for screen readers from its toolbar.

## Comments

A comment is a note attached to something. Select any highlight, drawing, text note, or image and its small toolbar has a Comment button. To comment on a passage without highlighting it yourself, select the text and press [[⌥⌘M]].

Press [[C]] for the Comments tool and the sidebar gains a **Comments** tab listing every comment in the document, including ones that were already in the file from other people. Click one to go to it.

## Sticky notes

With the Comments tool on, click any empty spot on a page to leave a sticky note there. Or right-click anywhere, in any tool, and choose **Add Comment Here**.

Notes stay visible and clickable whichever tool you're using. Drag one to move it.

## Changing and removing markup

Click a piece of markup with the Select tool ([[V]]) to select it. Its toolbar lets you recolor it, comment on it, or delete it, and [[Delete]] removes it too.

Deleting shows a small bar with Undo, in case that wasn't what you meant. [[⌘Z]] works as well, and keeps working after you save.

## Remembered settings

Each tool keeps its own color, thickness, opacity, and size between documents and between launches. If something is selected when you change a setting, the change applies to that one thing and the default stays as it was.
